# 콘텐츠 공장 — 장수한우곱창 백석직영점

계획을 세워두고, 주마다 "이런 사진 찍으세요" 미션을 받고,
사진을 올리면 **네이버 소식글 · 인스타 캡션 · 당근 소식**을 한 번에 만들어 주는 앱.

```
월 1회   AI가 이달 콘텐츠 계획 제안 → 사장님이 확인·수정 → 저장
주마다   앱이 이번 주 미션을 보여줌 (주제 + 찍어야 할 사진)
그때그때 사진 올리기 → 글 3종 생성 → 복사해서 발행 → 기록 저장
```

발행 기록이 쌓이면 나중에 **"소식글을 올린 주에 순위가 올랐나"** 를 순위트래커 데이터와 맞춰 볼 수 있다.

---

## 구성

```
index.html                     화면 (미션 / 글 만들기 / 계획)
netlify/functions/
  _config.js                   지점 설정 ← 다른 지점용으로 복사할 때 여기만 수정
  _google.js                   구글 시트 읽기·쓰기 (서비스 계정)
  plan.js                      계획 조회·AI 제안·저장·완료 처리
  generate.js                  사진 + 미션 → 채널별 글 생성
  publish.js                   발행 기록 저장
```

**사진은 저장하지 않는다.** AI가 보고 글만 쓰고 버린다.

## Netlify 환경변수

| 이름 | 값 |
|---|---|
| `GOOGLE_CREDENTIALS` | 서비스 계정 JSON 전체 (한 줄로) |
| `SHEET_ID` | 콘텐츠 계획 스프레드시트 ID |
| `GEMINI_API_KEY` | Gemini 키 (AI Studio 키 사용 가능) |
| `SOLAPI_API_KEY` | 촬영 알림 문자용 (선택) |
| `SOLAPI_API_SECRET` | 〃 |
| `SOLAPI_FROM` | 등록된 발신번호 |
| `SOLAPI_TO` | 받을 번호 |

솔라피 값이 없으면 알림만 건너뛰고 나머지는 정상 동작한다.

⚠️ 스프레드시트를 **서비스 계정 이메일에 편집자로 공유**해야 한다.
탭(`콘텐츠계획`, `발행기록`)은 처음 실행할 때 자동으로 만들어진다.

## 다른 지점용으로 복제하기

1. 이 폴더를 통째로 복사
2. `netlify/functions/_config.js` 의 `BRANCH`, `FULL_NAME`, `AREA_KEYWORDS` 수정
3. 새 스프레드시트를 만들고 `SHEET_ID` 만 바꿔서 Netlify에 배포

지점마다 계획과 기록이 따로 관리된다.

## 촬영 알림

`netlify.toml` 의 schedule 설정으로 **화요일·금요일 오전 10시(KST)** 에 자동 발송된다.

- 이번 주 남은 미션이 있을 때만 보낸다 (알림 피로 방지)
- SMS 기준 건당 13원, 월 8건이면 약 104원
- 수동 확인: `/.netlify/functions/notify-mission`

발송 시각을 바꾸려면 `netlify.toml` 의 cron 을 수정한다 (UTC 기준, KST = UTC+9).
